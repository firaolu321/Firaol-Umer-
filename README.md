# Firaol Umer Mohammed - Professional Portfolio Website

A modern, responsive, and fully interactive personal portfolio website built for **Firaol Umer Mohammed**, an Accounting and Finance graduate from Oda Bultum University. 

Designed with clean typography, smooth scrolling, dark/light mode toggling, and fully optimized layouts to showcase professional experience, academic achievements, leadership, and technical proficiencies.

---

## Features

* **Responsive Design:** Built with Tailwind CSS, ensuring flawless scaling across mobile phones, tablets, and desktop displays.
* **Dark / Light Mode:** Integrated dynamic theme switcher with persistent user preference storage via `localStorage`.
* **Professional Sections:**
  * **Hero & Bio:** Quick professional summary, contact info, and status indicator.
  * **Professional Objective:** Overview of career goals and academic foundation (CGPA 3.60/4.00).
  * **Experience Timeline:** Detailed breakdown of accounting internship at *Habro Finance and Economic Development Planning*.
  * **Skills Matrix:** Categorized proficiencies covering financial software (QuickBooks, SAP, Oracle Financials, Peachtree, IBEX) and core competencies.
  * **Leadership & Extracurriculars:** Highlighting roles such as Deputy Speaker of Parliament (OBUSU) and Finance Manager.
  * **Contact & Socials:** Direct mail, phone, and professional network links (LinkedIn, Facebook, X).
